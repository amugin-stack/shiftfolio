# Privacy review

This portfolio is a fresh source copy. It does not contain the original Git history, a database export, customer records, environment files, or deployment credentials. The interface runs against local demonstration data. Files under `reference/` are preserved source examples for review; they are not connected to a live service.

The source review covered the tracked files at the original repository's `origin/main` and the files selected for this portfolio. The original tree had hard-coded project URLs, account addresses, an admin-address example, and operational planning notes. These were removed, replaced with reserved example values, or left out of the portfolio. Credential-looking values in tests were synthetic fixtures. A redacted Gitleaks scan of the original source tree reported no findings. No production service or database was queried during this review.

The publication boundary excludes `.env*`, build output, dependencies, logs, database dumps, uploads, exports, backups, local service state, and the original repository history. It also excludes the original planning and release notes, which contained deployment context and historical author details. Example fixtures use synthetic identities and phone numbers. The project-specific URL and identifier were removed from migrations, scripts, documentation, and test guards. The two screenshots in `docs/images/` were visually reviewed: they show only the local synthetic demo interface and no browser chrome, account details, or service URLs.

Run `npm run scan:privacy` before publishing or merging changes. The scan rejects private keys, provider secret patterns, hosted project URLs, the production domain, non-example email addresses, and local data artifacts. It runs without credentials or network access. A reviewer should still inspect any new fixture, screenshot, asset, or document before publication; pattern checks cannot establish that every name or image is safe to share.
